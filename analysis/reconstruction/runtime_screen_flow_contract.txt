runtime_screen_flow_contract
Purpose: port-facing contract for the original help, legend, and level-intro screens.
Authority: $0E05 menu order, $110E zero-terminated VDU output, $111B compact text decode, $1145 help, $1175 legend, and $11FE level intro.
Artwork previews are intentionally omitted here; graphics are Mode 2 and are covered by composed_sprite_sheet.png and the renderer contracts.

screen_order
1 $1145 controls/help screen
2 $1175 object legend screen
3 $11FE level intro after starting a game

required_target_order
$11FE displays the first level_units entries for levels 1-5, then caps the displayed count at five. This display count is distinct from the inclusive highest-required-slot state used by gameplay setup.
$3F KEY
$3E RING

port_rules
Preserve the three screens and their original order.
Preserve compact text decoding and destination offsets rather than inventing a new layout.
Preserve the required-target sound/wait between glyphs.
Do not decode the graphic bytes as Mode 5; this runtime uses BBC/Electron Mode 2.
