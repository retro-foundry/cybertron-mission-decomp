movement_parity_note
$1735 seeds all four player starts with even Y values for both cells, but $1718/$16BE movement can later make object Y odd. Ports need both destination sequences.
$1849-$1863 draws player objects $10/$11 with store mode 1 on phase 3 when $0082 is zero, then saves visible graphics in $008E/$008D.

port_rules
Preserve the odd-Y renderer source order and destination offsets exactly; it is not row-major over the 24-byte source record.
Use the player-start layer digests as isolated renderer checks after validating source records and before validating full frames with room/status/object layers.
Do not treat these layer digests as gameplay-state frames; randomized object placement and collision/update side effects are intentionally out of scope.
