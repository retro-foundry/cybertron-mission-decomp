runtime_control_input_reference
scope=$0E05-$0E84 attract/input wait, $13AA/$2466 INKEY helpers, $15C3-$1634 active input, $1287 joystick, $2470 sound toggles
purpose=port-facing control flow reference; use runtime_player_movement.txt for the wider movement/shot/hazard tables

inkey_helper_semantics
$13AA and $2466 both call OSBYTE $81 with Y=$FF and X set to the negative INKEY code, then CPX #$00; BEQ means not pressed, nonzero X means pressed.
$2464 is the Escape wrapper: X=$8F then falls through to $2466.

control_key_codes
Space/start        inkey_x=$9d signed_x=-99 effect=$0E2E sets $0CEB=0 and returns carry set
Escape/menu        inkey_x=$8f signed_x=-113 effect=$0E2E returns carry clear; active $15C3 unwinds stack and jumps $0E05
M/fire             inkey_x=$9a signed_x=-102 effect=$1609 returns current fire state in X for $15C3 edge latch
P/pause            inkey_x=$c8 signed_x=-56 effect=$15C3 enters pause loop
R/resume           inkey_x=$cc signed_x=-52 effect=$15C3 exits pause loop
S/sound on         inkey_x=$ae signed_x=-82 effect=$2470 stores $0CEA=0
Q/sound off        inkey_x=$ef signed_x=-17 effect=$2470 tries sound ids $0C/$10 then stores $0CEA=1

keyboard_movement_codes_from_27dc
source_y_delta=$27D4 source_x_delta=$27D8 source_inkey=$27DC; multiple pressed movement keys accumulate deltas before $16E1 resolves direction.

attract_wait_flow_0e2e
$0E2E sets $2706=4, clears $0076-$0079, sets $0075=2, and disables IRQs with SEI only when $0C03 is nonzero.
Each loop calls $1307 with A=2, then $1341, then scans Space, Escape, joystick fire, and timeout counters.
Space pressed: stores $0CEB=0, executes CLI, returns SEC.
Joystick fire pressed through OSBYTE $80 X=0: stores $0CEB=1, executes CLI, returns SEC.
Escape pressed: returns CLC without the Space/fire CLI path.
Timeout after $0076/$0075 counters expire: returns CLC.

active_input_flow_15c3
$15C3 calls $2470 before clearing input deltas, so S/Q are polled once per active input frame.
It clears $003F/$0040/$0C01, then selects keyboard $1609 when $0CEB=0 or joystick $1287 when $0CEB!=0.
Fire edge: if previous $0C98 is zero and current returned X is nonzero, $003E is set to 1; then current X is stored to $0C98.
Escape: $2464 nonzero triggers four PLA instructions and JMP $0E05, so a port should leave the active frame path immediately.
Pause: P through $2466 enters a tight wait loop that repeatedly scans R through $2466; only R returns to active play.

joystick_flow_1287
OSBYTE $80 channel X=1 adjusts $003F with Y<$40 => +1 and Y>=$C0 => -1.
OSBYTE $80 channel X=2 adjusts $0040 with Y<$40 => +1 and Y>=$C0 => -1.
OSBYTE $80 channel X=0 returns fire in X&1 to the same $15C3 edge latch used by keyboard fire.

sound_toggle_flow_2470
S key pressed: $0CEA=0, enabling later sound dispatch in $21EA.
Q key pressed: calls $21EA with sound ids $0C and $10 before storing $0CEA=1; those feedback sounds are therefore suppressed if sound was already disabled.
$21EA returns immediately when $0CEA is nonzero, so ports should preserve $0CEA as the global sound-off gate.

port_rules
1. Preserve $0CEB as the selected input mode set by attract start: Space=keyboard, joystick fire=joystick.
2. Preserve INKEY helper polarity: zero means not pressed, nonzero means pressed.
3. Preserve $0C98/$003E as a rising-edge fire latch; do not spawn repeated shots from a held fire input.
4. Preserve Escape as an immediate return-to-menu transfer from active input, not a normal pause or death transition.
5. Preserve the pause loop's P-to-enter/R-to-exit behavior and its lack of normal frame progress while paused.
6. Preserve Q sound-off feedback gating: it only plays while sound was enabled before Q is stored.
