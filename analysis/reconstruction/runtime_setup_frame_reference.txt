# Cybertron setup-frame reference

Scope: controlled deterministic vectors for target-code generation followed by the $1735 setup path.
The resulting screen includes room render, status panel, enemies, and room-target objects.
It also exports a second digest after the immediate $1849-$1863 visible-player draw/save subpath.
Each scenario includes a port-state snapshot for seeded player fields, phase/input flags, target arrays, and placed render objects.
It excludes later $1849 collision/input checks, shots, hazards, spook release, sound, and palette effects.

RNG inputs are explicit three-byte seeds plus an explicit carry flag. This keeps the vectors
portable even though the original caller context owns carry into $1D61.
