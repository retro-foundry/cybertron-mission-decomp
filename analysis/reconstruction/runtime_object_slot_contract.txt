Authority: projectile arrays are not render-object slots; they use $0C1E/$0C26/$0C2E/$0C36/$0C3E/$0C46/$0C4E/$0C56 and draw through $1AE9/$1B0E.

port_rule: do not merge these with render object slots or logical item slots; only collision/recycle routines bridge them.

port_summary
Render slot i owns visible object position/pointer/graphic arrays; logical slot s aliases render slot s+$14 for item/enemy/target placement.
Only lifecycle state $01 participates in active enemy scheduling and shot/object hit scanning; states $02-$05 are hit-animation/retire states.
Room target slots 0-6 are not generic logical slots: they project to logical $22-$28/render $36-$3C only when $243E/$244A place them for the current room.
Shot/hazard slots are a separate 8-entry projectile array with different allocation/counter rules from render-object slots.
