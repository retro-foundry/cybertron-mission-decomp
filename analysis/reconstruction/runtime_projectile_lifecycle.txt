draw_collision_order_189c_195b
Frame phase before player input: $189C scans slots 7..0, calls $1AE9 to erase/toggle the previous visible two bytes, then $1B0E to draw/test current bytes.
$1AE9 only runs when $0C56[X] != 0; it toggles previous pointer bytes Y=1 and Y=0 with EOR #$2A, and clears $0C56 if direction $0C4E[X] is now inactive.
$1B0E returns immediately for inactive $0C4E[X]<0; otherwise it sets $0C56=1, ORs the masked current screen bytes into $0030, toggles the same two bytes with EOR #$2A, and jumps to $2163 if $0030 != 0.
Frame phase after player input: $1937 scans slots 7..0 through $1B87 movement, optionally spawns player shots and hazards, then $194E scans slots 7..0 through $1B41 expiry.

expiry_mask_classes_1b41
Authority: $1B41 reads current pointer bytes Y=1 then Y=0, masks each with $AA, and expires the slot for only these classes or for out-of-bounds $1C8D.
masked_value action

object_hit_and_recycle_2163_22d0
Authority: $2163 first checks direct player overlap only when $0082 == 0. Hit width is X delta 0..2 and Y delta 0..3; on hit it calls $21D8 and jumps to $1964.
If no player hit, $2163 scans object indices $14-$2B with $0C53[Y] == 1. Object hit width is X delta 0..2 and Y delta 0..1.
On object hit it sets $0C53[Y]=2. Player shot slots X<4 score (graphic_id-$29)*2 through $22E6 and decrement $0080. Hazard slots X>=4 copy hit graphic id through $22D0 into the first free logical item slot below $0C.
$21D8 saves current pointer to previous pointer, then calls $1B77 and jumps to $1AE9, so counter decrement and visible-byte erase use the same deactivate path.
$22D0 preserves the hit graphic id in Y, finds a free $0C67 slot via $22C5, refuses slots >=$0C, writes $2F14[X]=graphic id, marks $0C67[X]=1, stores $003A=X, then jumps to $1DD1 for random placement.
